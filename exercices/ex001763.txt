\exercice{1763, maillot, 2001/09/01}

\enonce
Dans \( \Rr^2 \) euclidien, les ensembles suivants sont-ils compacts ?
\begin{itemize}
  \item \( A = \{(x,y)\in\Rr^2 \mid \frac12 \le \| (x,y)\| \le 2\ \text{et}
        \ xy = 1\} \).

  \item \( B = \{(x,y)\in\Rr^2 \mid \frac12 < \| (x,y)\| \le 2\ \text{et}
        \ xy = 1\} \).

  \item \( C = \{(x,\cos n)\in\Rr^2 \mid 0\le x \le 18 \ \text{et}\ n\in\Nn\} \).
\end{itemize}
\finenonce

\noindication

\nocorrection

\finexercice
