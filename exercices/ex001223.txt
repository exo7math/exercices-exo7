\exercice{1223, legall, 1998/09/01}

\enonce
Étudier la continuité, la dérivabilité, la continuité de la dérivée pour les applications suivantes :
\begin{enumerate}
  \item \( \displaystyle { f :x \mapsto \hbox{sin }(\frac{1}{x}) } \) si \( x\not= 0 \) et \( f(0) = 0 \).

  \item \( \displaystyle { g :x \mapsto x \hbox{sin }(\frac{1}{x}) } \) si \( x\not= 0 \) et \( g(0) = 0 \).

  \item \( \displaystyle { h :x \mapsto x^2 \hbox{sin }(\frac{1}{x}) } \) si \( x\not= 0 \) et \( h(0) = 0 \).
\end{enumerate}
\finenonce

\noindication

\nocorrection

\finexercice
