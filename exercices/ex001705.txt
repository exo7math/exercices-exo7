\exercice{1705, barraud, 2003/09/01}

\enonce
Déterminer toutes les suites \( (u_n) \) telles que :
\[
  \begin{cases}
    \forall n\in \Nn \quad u_{n+3}+u_{n+2}+u_{n+1}+u_n = 0 \\
    u_0 = 1, u_1 = 2, u_2 = 0
  \end{cases}
\]
Résoudre l'équation différentielle :
\[
  \begin{cases}
    f'''+f''+f'+f = 0 \\
    f(0) = 1, f'(0) = 0, f''(0) = 0
  \end{cases}
\]
\finenonce

\noindication

\nocorrection

\finexercice
