\exercice{234, ridde, 1999/11/01}

\enonce
Soit \( 0 \le p \le n \).
\begin{enumerate}
  \item Montrer par récurrence sur \( n \) que \( \sum\limits_{k = p}^n C_k^p = C_{n + 1}^{p + 1} \).

  \item Écrire ces égalités pour \( p = 2 \) et \( p = 3 \).

  \item En déduire les sommes
        \[
          S_2' = 1\cdot 2 + 2\cdot 3 + \ldots + (n-1)\cdot n
          \qquad S_2 = 1^2 + 2^2 + \ldots + n^2
        \]
        \[
          S_3' = 1^2\cdot 2 + 2^2\cdot 3 + \ldots + (n-1)^2\cdot n
          \qquad S_3 = 1^3 + 2^3 + \ldots + n^3
        \]
\end{enumerate}
\finenonce

\noindication

\nocorrection

\finexercice
