# exo7math/exercices-exo7

## Présentation

Ce répertoire contient les sources LaTeX des exercices du site "Exo7" [http://exo7.emath.fr/search.php](http://exo7.emath.fr/search.php)

Il contient également les sources des fiches (des listes d'exercices, qui peuvent correspondre à des chapitres).

En octobre 2026, le format a été légèrement modifé. Les anciens fichiers sont encore disponibles dans le répertoire `oldexercices`.
